# ladder-content

Daily TikToks for @theladderrr, built from the book and published via Metricool.

* `clips/` footage library, `clips/clips.json` text placement per clip
* `assets/` cover, logo, 3D book outro
* `tools/render.py` renderer, `tools/clipinfo.py` registers new clips, `tools/book3d.py` rebuilds the outro
* `manuscript.md` the book
* `log.csv` every published video

Finished videos live on the `media` branch (only the last few days are kept).
